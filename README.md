# Oral Disease Image Classification

AI-powered system for classifying oral disease images into 6 categories using deep learning.

## 🦷 Overview

This project builds, compares, and deploys an AI system that classifies oral disease images into their correct categories. It includes a custom CNN, three pretrained models with transfer learning, hyperparameter tuning, comparative analysis, and a Flask web application for deployment.

## 🏥 Disease Classes

| # | Class | Description |
|---|-------|-------------|
| 0 | **Calculus** | Hardened dental plaque (tartar) |
| 1 | **Caries** | Dental cavities / tooth decay |
| 2 | **Gingivitis** | Gum inflammation and disease |
| 3 | **Hypodontia** | Developmental absence of teeth |
| 4 | **Mouth Ulcer** | Oral sores / canker sores |
| 5 | **Tooth Discoloration** | Staining or color changes in teeth |

## 🧠 Models

### 1. Custom CNN (Built from Scratch)
- 4 convolutional blocks with BatchNormalization + MaxPooling
- Progressive filter sizes: 32 → 64 → 128 → 256
- Dense classifier head with Dropout regularization

### 2. VGG16 (Pretrained - Transfer Learning)
- ImageNet-pretrained VGG16 backbone (frozen)
- Custom classification head with GlobalAveragePooling

### 3. ResNet50 (Pretrained - Transfer Learning)
- ImageNet-pretrained ResNet50 backbone (frozen)
- Custom classification head with GlobalAveragePooling

### 4. EfficientNetB0 (Pretrained - Transfer Learning)
- ImageNet-pretrained EfficientNetB0 backbone (frozen)
- Custom classification head with GlobalAveragePooling

### Hyperparameter Tuning
- The best pretrained model is fine-tuned by unfreezing top 30% of layers
- Learning rates tested: 1e-4, 5e-5, 1e-5
- Best configuration is selected based on validation accuracy

## 🚀 How to Run

### Step 0: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 1: Prepare the Dataset
```bash
python 01_data_preparation.py
```
This organizes the raw data into `dataset/train`, `dataset/val`, and `dataset/test` folders.

### Step 2: Train All Models
```bash
python 02_train_models.py
```
This trains all 4 models, performs hyperparameter tuning, generates plots, and saves the best model.

### Step 3: View Comparative Analysis
```bash
python 03_comparative_analysis.py
```

### Step 4: Run the Flask App
```bash
cd flask_app
python app.py
```
Open your browser to `http://localhost:5000`

## 📊 Training Configuration

| Parameter | Value |
|-----------|-------|
| Image Size | 224×224 |
| Batch Size | 32 |
| Max Epochs | 25 |
| Optimizer | Adam |
| Loss | Categorical Cross-Entropy |
| Data Augmentation | Rotation, Shift, Zoom, Flip, Shear |
| Early Stopping | patience=7 |
| LR Reduction | factor=0.5, patience=3 |

## 🌐 Flask App Features

- Drag-and-drop image upload
- Real-time disease prediction with confidence scores
- All-class probability visualization
- Disease information (description, severity, recommendation)
- REST API endpoint at `/api/predict`
- Responsive dark-themed UI
